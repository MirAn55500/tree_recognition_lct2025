# Описание файлов экспериментов

## Сбор и предобработка данных

*   `get_internet_data.py` - Скрипт для автоматизированного сбора изображений (фото по породам и болезням деревьев) из интернета, формирующий первичный датасет.
*   `gemini_annotation.py` - Инструмент для автоматической разметки предоставленного организаторами датасета (с выделенными отдельными растениями) с использованием VLM (Vision-Language Model), в частности, модели Gemini.
*   `datapreprocess.ipynb` - Jupyter Notebook, содержащий функции для нормализации и предобработки аннотаций, полученных от VLM. Включает логику для преобразования различных форматов входных данных в унифицированную структуру JSON, а также для обработки вероятностей и бинарных признаков.
*   `pipeline.ipynb` - Jupyter Notebook, демонстрирующий пайплайн обработки изображений: детекция объектов с помощью Grounding DINO, сегментация масок с помощью SAM2, и классификация видов деревьев с помощью BioCLIP. Также включает трансформацию исходных аннотаций в целевой формат.
*   `prepare_dataset.ipynb` - Jupyter Notebook, предназначенный для подготовки финального датасета из JSON-аннотаций. Выполняет валидацию структуры JSON-файлов, собирает уникальные словари видов и болезней, а затем формирует единый CSV-файл и отчет о валидации, используемые для дальнейшего обучения моделей.
*   `prepare_class_data.ipynb` - Jupyter Notebook, который обрезает изображения объектов (деревьев, кустарников) по bounding box'ам, извлеченным из аннотаций. Сохраняет обрезанные изображения в отдельные папки, структурированные по классам (породам или болезням), для использования в задачах классификации.

## Обучение и валидация моделей

*   `bioclip_validate.ipynb` - Jupyter Notebook для оценки качества модели BioCLIP на задачах классификации пород деревьев и заболеваний.
*   `efficientnet_train_val.ipynb` - Jupyter Notebook для обучения и валидации моделей семейства EfficientNet на задачу классификации пород.
*   `prop_model.ipynb` - Jupyter Notebook, описывающий процесс обучения регрессионной модели для предсказания различных характеристик деревьев (например, наличие дупел, трещин, процент сухих ветвей) на основе эмбеддингов, полученных от DINOv3. Включает подготовку данных, архитектуру модели, обучение и оценку метрик.
*   `train.ipynb` - Jupyter Notebook для комплексного обучения модели, которая объединяет задачи регрессии и классификации (например, классификация болезней). Использует эмбеддинги, полученные от DINOv3 после сегментации объектов с помощью SAM2. Включает подготовку данных, определение архитектуры модели (с отдельными головами для регрессии и классификации), функции обучения, оценки и визуализации метрик.
*   `tree_crop.ipynb` - Jupyter Notebook, который использует Grounding DINO для обнаружения объектов (деревьев, кустарников) на изображениях и обрезает их. Сохраняет обрезанные изображения в указанную директорию и создает CSV-манифест с метаданными каждого кропа.
*   `yolo_finetune.ipynb` - Jupyter Notebook, демонстрирующий процесс дообучения и использования модели YOLO для детекции объектов. Интегрирует YOLO с Grounding DINO и SAM2 для гибридной детекции и сегментации, а также включает функции для не-максимального подавления (NMS) и визуализации результатов.
