# Платформа дообучения моделей для анализа деревьев

Платформа для создания, редактирования аннотаций и дообучения моделей машинного обучения для анализа состояния деревьев.

## Возможности

### 📁 Управление датасетами
- Создание и управление датасетами изображений
- Загрузка изображений в датасеты
- Просмотр статистики по датасетам

### ✏️ Редактор аннотаций
- Графический интерфейс для создания и редактирования аннотаций
- Автоматическая генерация аннотаций с помощью VLM (Qwen2.5-VL)
- Поддержка аннотирования:
  - Bounding boxes для деревьев и кустарников
  - Классификация видов растений
  - Оценка характеристик (дупла, трещины, повреждения)
  - Диагностика заболеваний
  - Процент сухих ветвей

### 🤖 Обучение моделей
- Обучение моделей классификации видов
- Обучение моделей диагностики заболеваний
- Обучение моделей регрессии характеристик
- Использование предобученных эмбеддингов DINOv3

### 📊 Управление моделями
- Просмотр обученных моделей
- Скачивание моделей
- Интеграция с существующей системой предсказаний

## Быстрый старт

### Windows
1. Запустите `start.bat` - скрипт автоматически установит зависимости и запустит сервер
2. Откройте браузер и перейдите по адресу: http://localhost:7000

### Linux/macOS
1. Запустите `./start.sh` - скрипт автоматически установит зависимости и запустит сервер
2. Откройте браузер и перейдите по адресу: http://localhost:7000

### Ручная установка
1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите сервер:
```bash
cd backend
python main.py
```

3. Откройте браузер и перейдите по адресу: http://localhost:7000

## Использование

### Создание датасета
1. Перейдите на вкладку "Датасеты"
2. Введите название и описание датасета
3. Нажмите "Создать датасет"
4. Загрузите изображения в датасет

### Аннотирование
1. Перейдите на вкладку "Аннотации"
2. Выберите датасет
3. Выберите изображение для аннотирования
4. Создайте или отредактируйте аннотации:
   - Укажите bounding box
   - Выберите вид растения
   - Оцените характеристики (0-1)
   - Добавьте информацию о заболеваниях
   - Укажите процент сухих ветвей

### Автоматическая генерация аннотаций
1. Выберите изображение
2. Нажмите "Сгенерировать с VLM"
3. Введите API ключ OpenRouter
4. Дождитесь генерации аннотации
5. При необходимости отредактируйте результат

### Обучение моделей
1. Перейдите на вкладку "Обучение"
2. Выберите датасет и тип модели
3. Настройте параметры обучения
4. Нажмите "Начать обучение"
5. Дождитесь завершения обучения

## API

### Датасеты
- `GET /api/datasets` - Список датасетов
- `POST /api/datasets` - Создание датасета
- `POST /api/datasets/{name}/upload` - Загрузка изображений
- `GET /api/datasets/{name}/images` - Список изображений

### Аннотации
- `GET /api/datasets/{name}/images/{image}` - Получить аннотацию
- `POST /api/datasets/{name}/images/{image}/annotation` - Сохранить аннотацию
- `POST /api/datasets/{name}/images/{image}/generate` - Сгенерировать аннотацию

### Обучение
- `POST /api/training/start` - Запустить обучение
- `GET /api/models` - Список моделей

## Интеграция с VLM

Для автоматической генерации аннотаций используется модель Qwen2.5-VL через OpenRouter API.

1. Получите API ключ на https://openrouter.ai/
2. Используйте функцию генерации аннотаций в интерфейсе

## Технические детали

- **Backend**: FastAPI
- **Frontend**: HTML/CSS/JavaScript
- **ML**: PyTorch, Transformers, OpenCLIP
- **Feature Extraction**: DINOv3
- **VLM**: Qwen2.5-VL через OpenRouter
